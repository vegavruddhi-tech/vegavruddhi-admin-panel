# ⚙️ Vegavruddhi Admin Panel (Core System)

Central administrative management application featuring system administration tools, master data controls, and the FSE operational dashboard.

---

## 📐 Architecture

```
vegavruddhi-admin-panel/
├── backend/          # Central Express.js backend services
└── fse-dashboard/    # FSE Management & Operations Dashboard
```

---

## ✨ Key Features

- 🔑 **Master User Management**: Admin permissions, employee onboarding, role assignments, and access revoked lists.
- 🏬 **FSE Operations Dashboard**: Control tower monitoring active field sales executives, location logs, and form inputs.
- 🗄️ **Master Database Utilities**: High-performance backend routing and database management tools.

---

## 🚀 Quick Start Guide

### 1. Backend Service
```bash
cd backend
npm install
npm start
```

### 2. FSE Dashboard Frontend
```bash
cd fse-dashboard
npm install
npm start
```
